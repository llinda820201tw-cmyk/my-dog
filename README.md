# 🌭 Dachshund Finance - 臘腸狗主題輕量記帳 App

一款結合**臘腸狗可愛視覺**、**極致低門檻記帳**與**即時財務視覺化**的個人理財 Flutter App。

---

## 🌟 核心特色與功能 (Key Features)

- **🐶 臘腸狗客製化主題**：內建 3 款精美背景主題，讓記帳過程更療癒。
- **📅 日期選取與時間管理**：支援彈性選擇交易日期，隨時補記或預記帳務。
- **⚡ 快速記帳與固定收支範本**：
  - 日序開銷自由留白填寫，減少分類壓迫感。
  - 內建常用固定收支（如房租、薪水），只需輸入金額即可一鍵帶入。
- **📊 雙重財務視覺化圖表**：
  - **每個月結餘圓餅圖**：透過動態圓餅圖即時呈現當月收入與支出比例。
  - **年末財務統計分析**：彙整全年總收支與趨勢，方便年終財務盤點。
- **🎉 遊戲化與正向獎勵機制**：當月收支呈正成長或連續存錢時，觸發彩帶特效與暖心激勵語錄。
- **🔒 100% 本地資料隱私**：所有帳務資料均儲存於手機本地，離線可用且絕不外洩。

---

## 🛠️ 技術選型 (Tech Stack)

- **前端框架 (Framework)**：Flutter (Dart)
- **本地資料庫 (Database)**：SQLite (`sqflite`) — 零延遲、完全離線儲存
- **視覺圖表 (Charts)**：`fl_chart` — 動態圓餅圖與統計圖表
- **動畫特效 (Effects)**：`confetti` — 記收入與達標時的粒子噴發效果
